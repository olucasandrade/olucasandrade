## O que faz

O Trevo é uma API de proxy CORS e ferramenta de teste de API. Você pode enviar requisições HTTP e WebSocket, salvá-las, gerenciar parâmetros, cabeçalhos e conteúdo do corpo, e compartilhar coleções com sua equipe.

## Como usar

Abra [app.trevo.rest](https://app.trevo.rest), crie uma requisição, escolha o método e a URL, e envie. Requisições WebSocket abrem um painel de conexão ao vivo para inspecionar frames em tempo real.

Fluxos típicos:

- Faça proxy de uma requisição frontend para um backend sem headers CORS.
- Salve um conjunto de requisições de staging para testes repetidos.
- Reproduza um handshake WebSocket e observe os frames de mensagem.
