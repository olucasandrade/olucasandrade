## O que faz

O rsight é uma ferramenta rápida de busca no terminal para macOS. Ele pesquisa arquivos, pastas, conteúdo de arquivos e conversas de IA (Claude Code, Cursor, Codex) em todo o diretório home a partir de uma única interface.

## Como usar

Instale via Homebrew ou cargo:

```bash
brew install olucasandrade/tap/rsight
# ou
cargo install rsight
```

Inicie o rsight e digite sua consulta. Os resultados aparecem em streaming enquanto você digita:

```bash
rsight "user service auth"
```

Encontre toda menção a uma função no código e nos logs de chat:

```bash
rsight "handleCheckout" --include-ai
```

Abra a primeira correspondência diretamente no seu editor:

```bash
rsight "config.go" --open
```
