## What it does

Trevo is a CORS proxy and API testing tool. You can send HTTP and WebSocket requests, save them, manage parameters, headers, and body content, and share collections with your team.

## How to use

Open [app.trevo.rest](https://app.trevo.rest), create a request, pick the method and URL, and hit send. WebSocket requests open a live connection panel so you can inspect frames in real time.

Typical flows:

- Proxy a frontend request to a backend that lacks CORS headers.
- Save a set of staging API requests for repeated testing.
- Replay a WebSocket handshake and watch message frames.
