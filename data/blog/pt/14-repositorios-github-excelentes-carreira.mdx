A área de tecnologia é enorme, e muitos podem ter dificuldades na hora de se organizar nos estudos para entrar na área, principalmente no início. Apesar da área ter muitos recursos disponíveis, o fato dela ser tão abrangente nos deixa "perdido" na caça por recursos, ajudas, ideias, entre outras coisas.

E isso é completamente normal! Por isso mesmo, no Github, existem diversos repositórios abertos feitos por pessoas que querem ajudar em vários setores e abordando diversas pautas diferentes, exatamente para ajudar a turbinar seus estudos. Sabendo a quantidade de repositórios úteis, não pude deixar de escrever sobre os 14 que mais gostei de ter visto na plataforma e que podem ajudar vocês como já me ajudou.

Lembrando que o Github é uma plataforma que hospeda código fonte por meio do controle de versão (o Git). Se você quer entender mais sobre como funciona o Git e o Github, não deixe de conferir meu artigo sobre [**aqui**](https://andradelucas.medium.com/git-e-github-entendendo-como-funciona-o-controle-de-vers%C3%A3o-4a85d363c615).

## 1 - Design Resources for developers

Como o nome já diz, o repositório armazena [**diversos recursos gratuitos relacionados a design**](https://github.com/iuricode/recursos-gratuitos), e o povo do front-end vai encontrar um mundo pra explorar num só endereço. Desde fotos e ícones para usar no seu projeto, até bibliotecas CSS ou de frameworks como React e Vue, é realmente um repositório muito grande e útil para seu projeto ou simplesmente para aprender.

## 2 - Github Readme Status

Dependendo do usuário, você vai querer customizar seu Github. Aliás, é o seu portfólio, onde ficam armazenados seus projetos mais importantes. Pra isso, Anurag Hazra criou uma espécie de template para armazenar suas principais atividades no Github. Pra quem gosta de deixar seu perfil mais organizado e bonito, [**vale a pena dar uma lida**](https://github.com/anuraghazra/github-readme-stats).

## 3 - Awesome Hacking Resources

Ideal para estudantes de segurança da informação, [**o repositório contém diversos materiais para estudo do tema**](https://github.com/vitalysim/Awesome-Hacking-Resources), que é tão abrangente e envolve muitos conceitos. Canais no Youtube,análises de malware e fóruns são uns dos muitos tópicos que contém diversas referências maneiras e links externos.

## 4 – App Ideas

Um dos repositórios mais criativos e organizados que já vi. O [**App Ideas**](https://github.com/florinpop17/app-ideas) é isso que o nome diz mesmo… Um repositório lotado de ideias para desenvolvedores criarem suas aplicações. Mas tem alguns diferenciais: Seu readme separa as ideias em níveis de conhecimento. Calculadoras e Previewers para iniciantes, conversores de moedas e extensões do chrome para intermediários, até um clone do Instagram para mais avançados, entre muitos outros.

Além disso, o respositório possui uma espécie de to-do list dentro de cada ideia como uma lista de requisitos para ir fazendo aos poucos. Vale muito a pena dar uma olhada.

## 5 - Free Programming Books

A ebook foundation criou [**esse repositório sensacional**](https://github.com/EbookFoundation/free-programming-books) LOTADO de livros gratuitos para quem curte ler sobre programação e tecnologia. E pra quem não entende inglês ou simplesmente quer ler em outros idiomas, relaxa, tem em diversos idiomas, e separados por diversos tópicos dentro da tecnologia. Vale a pena demais se aprofundar!

## 6 - Public APIs

Quem nunca passou por uma dor de cabeça sem ideias, e só de ver uma API já quis implementar algo por cima? [**Esse repositório**](https://github.com/public-apis/public-apis) conta com várias APIs para te ajudar nisso, separado por temas e mostrando se precisam de autenticação ou não, entre outras coisas. Eu já vou usar umas APIs dali pra algum projeto, talvez…

## 7 - Javascript Testing: Best Pratices

[**Esse repositório**](https://github.com/goldbergyoni/javascript-testing-best-practices) contém diversos textos, redigidos e traduzidos em várias linguagens (inclusive em português) sobre testes feitos em javascript, além do Node. Mostrando diversas boas práticas sobre o assunto, o repositório promete te fazer gastar um bom tempo de leitura.

## 8 - The Art Of Command Line

Para os amantes do Linux, [**esse repositório**](https://github.com/jlevy/the-art-of-command-line) te deixa a par dos principais recursos do sistema, óbvio, no terminal, que é seu principal recurso. Com uma leitura detalhada, você consegue aprender muito sobre Linux na linha de comando só com esse repositório. Eu mesmo já favoritei pra ler mais a fundo, pois é muito conteúdo mesmo. Ah, e tem traduzido em português :)

## 9 - Developer Roadmap

Que repositório sensacional, sério… Um dos mais famosos do Github. Atualizado todo ano, o [**developer roadmap**](https://github.com/kamranahmedse/developer-roadmap) te ajuda a trilhar um caminho de aprendizado até se tornar um desenvolvedor Front-End, Back-End ou Devops.

São realmente muitos assuntos abordados pra cada área, desde os opcionais até os obrigatórios, que você deve saber para continuar. Ah, e antes mesmo de escolher sua área, certifique que você sabe os tópicos do canto esquerdo da imagem.

## 10 – Clean Code

O livro é muito conhecido, e provavelmente você já ouviu falar. O Clean Code te ajuda a criar um conceito de código limpo, legível e de fácil manutenção. Mas existem diversos repositórios no Github com informações sobre o livro adaptada para diversas linguagens e tecnologias. Então, aqui vai uma pequena lista:

- [**Clean Code - Javascript**](https://github.com/ryanmcdermott/clean-code-javascript)
- [**Clean Code - PHP**](https://github.com/jupeter/clean-code-php)
- [**Clean Code - .NET**](https://github.com/thangchung/clean-code-dotnet)
- [**Clean Code - Typescript**](https://github.com/labs42io/clean-code-typescript)
- [**Clean Code - Ruby**](https://github.com/uohzxela/clean-code-ruby)

Esses repositórios podem te ajudar a deixar seu código mais bonito, o que é um diferencial em um sistema decente ou para um empregador. Imagina você na linha de frente de um processo seletivo tendo que analisar diversos códigos lotados de gambiarras? 😐

## 11 - Coding Interview University

Por falar em processo seletivo… O [**Coding Interview University**](https://github.com/jwasham/coding-interview-university) é um repositório que reúne diversos temas para te preparar para processos de grandes corporações como engenheiro de software, como Google, Amazon, Facebook e Microsoft

O repositório realmente te deixa a par de tudo e, se aprofundando em todos os assuntos com dedicação (entenda, isso demanda **TEMPO**) você com certeza vai chegar em um processo seletivo muito bem preparado.

## 12 - Vagas

Para quem está em busca do primeiro emprego, esses repositórios podem realmente contribuir muito. Destinados a React, Flutter, Front e Back-End num geral, entre muitos outros, repositórios de vagas se fazem bem presentes no Github. Aqui vai uma pequena lista de alguns:

- [**Front-End**](https://github.com/frontendbr/vagas)
- [**Back-End**](https://github.com/backend-br/vagas)
- [**Flutter**](https://github.com/flutter-brazil/vagas)
- [**React**](https://github.com/react-brasil/vagas)
- [**Vue**](https://github.com/vuejs-br/vagas)
- [**Java**](https://github.com/soujava/vagas-java)
- [**QA**](https://github.com/qa-brasil/vagas)

Como ver as vagas? É só ir nas issues de cada repositório, onde as empresas hospedam e dão detalhes sobre a vaga e como entrar em contato! E não esqueçam de ver os perfis dos donos desses repositórios, que são as comunidades de cada área no Brasil que oferecem diversos conteúdos interessantíssimos.

## 13 - Contrate um Júnior/Estágio

Excelente iniciativa criada pela Aline Bastos, [**o repositório**](https://github.com/alinebastos/contrate-junior-estagio) te permite criar uma issue com suas informações, como se fosse uma espécie de currículo mesmo, para que empresas possam te encontrar e quem sabe entrar em contato posteriormente. Lembrando que o repositório é pra quem busca o PRIMEIRO EMPREGO na área.

## 14 - Front-End/Back-End Challenges

Por último, é importante para qualquer desenvolvedor que saiba o que vai encarar no mercado de trabalho. Por isso mesmo, esses repositórios vieram para ajudar a te dar um norte, com diversos desafios de empresas reais para ajudar a alavancar sua noção de mercado, tanto em front quanto em back-end.

- [**Front-End Challenges**](https://github.com/felipefialho/frontend-challenges)
- [**Back-End Challenges**](https://github.com/CollabCodeTech/backend-challenges)

No mais, obrigado pela leitura. Espero ter te ajudado a se organizar melhor na sua caminhada. Bom, se tiver alguma ideia ou um repositório útil para citar e contribuir com a comunidade, não esqueça de deixar seu comentário ou sugestão!
